# Numerical results and supplementary material

`results/` contains the inputs needed to regenerate reported comparisons, selected tables for browsing, illustrative traces and observable replay fixtures. It does not contain a preparation or review archive.

## Reproduction

```bash
python -B scripts/reproduce.py --out /tmp/safeprocess-results
```

Run from any directory by giving the script's absolute path. Outputs must be outside the checkout. The command verifies the one results manifest and then runs closed aggregation, evidence tables, 31 observable fixtures, the matched example and figure generation. No raw recordings, weights, fitting or model inference are needed. `--tex` uses TeX-rendered Computer Modern for the figures when the required TeX tools are installed. The default renderer works without TeX.

Individual commands keep the same `--root` and `--out` options:

```bash
python -B scripts/reproduce_closed.py --root . --out /tmp/safeprocess-closed
python -B scripts/reproduce_evidence.py --root . --out /tmp/safeprocess-evidence
python -B scripts/reproduce_observable.py --root . --out /tmp/safeprocess-observable
python -B scripts/matched_case.py --root . --out /tmp/safeprocess-matched
python -B scripts/reproduce_figures.py --root . --out /tmp/safeprocess-figures
```

## Data layout

- `results/data/`: closed primary/baseline/concern outcomes, reconstruction quality, history outcomes, temporal outcomes and labels, source blocks, margin and severity curves.
- `results/traces/`: useful, adverse, vetoed and native examples, with inference and evaluator data kept separate.
- `results/replay/`: 31 numerical fixtures and the fixed profiles needed for observable and matched-case replay.
- `results/tables/`: six selected summary tables for browsing. Full tables are regenerated into the chosen output directory.
- `results/metadata/native_graph.json`: retained graph-status evidence, including missing information.
- `results/manifest.json`: one checksum list for these result files. Runtime run identities are separate and are generated with each fresh experiment.

The inputs retain all original adverse outcomes and all 712 temporal observations per policy. No replacement operating point is selected. Native quality remains missing where no clean counterfactual exists. Source periods and checkpoints are dependent, and the temporal panel uses the same SWaT recording.

## Figures and trace selection

Figure generation writes `decision_layer.pdf`, `tradeoff.pdf`, `matched_trajectories.pdf`, `window_detail.pdf` and `severity.pdf`, with companion PNG files. The severity output includes the full checkpoint-curve CSV. The decision-layer overview is a method diagram and contains no empirical results.

The useful, adverse, vetoed and native traces retain their deterministic selection rule in each observable JSON's `rule` field. `trace_catalog.json` records the IDs and context/centre/scale locators. These are illustrative examples, not estimates of prevalence. The matched example concerns case `292fd580e6f4676f9bfd`, FourTank seed 23. It keeps candidate evidence, ranking and required gap fixed and compares each event score with its calibrated limit.
