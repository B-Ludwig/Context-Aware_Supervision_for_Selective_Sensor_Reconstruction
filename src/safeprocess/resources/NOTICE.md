The FourTank engineering mapping and SWaT topology/channel descriptions are authored mappings extracted from the study implementation. Their evidence citations remain in the YAML resources. These descriptions are not recordings and do not grant redistribution rights for externally acquired data. The Apache-2.0 repository license applies to the authored adapter code and mappings.

`paper_channels.json` records only the twelve configurations' ordered sensor names, component owners and identity encoding. It contains no learned statistics, calibration profiles or model weights.

The adapter uses declared system connections only. Hierarchy membership, shared parents and graph reachability through nonpeak components are not process-flag edges.
